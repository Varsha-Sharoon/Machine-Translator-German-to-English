# Machine-Translator-German-to-English
This project automatically translates German sentences to English using deep learning techniques. Users can input text or click to translate, and the model generates accurate English translations in real-time.

Tools & Technologies Used :-

Python, TensorFlow, Keras, NLTK, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, LSTM, Text Processing

Steps / Workflow :-

Collected and preprocessed German-English parallel text data.
Tokenized and padded sequences for model input.
Built and trained an LSTM-based sequence-to-sequence model for translation.
Evaluated translation quality using BLEU scores.
Implemented a user interface to input text and get translations automatically.

Results / Output :-

The model successfully translates German text to English with high accuracy and generates readable translations. BLEU scores show good alignment with human translations.

Conclusion / Insights :-

Deep learning models like LSTM can efficiently learn language mappings for machine translation. Preprocessing and tokenization significantly impact translation quality.
